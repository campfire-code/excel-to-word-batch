## 怎么用

**第一步：准备 Word 模板（.docx）**

在 Word 或 WPS 里把要替换的地方写成 `{列名}`，列名和 Excel 表头一字不差。例如表头是「姓名」「月薪」，模板里就写：

```
尊敬的 {姓名}：您的月薪为 {月薪} 元。
```

占位符写法要点：
- 用**英文半角**花括号 `{ }`。写成全角 `｛ ｝` 时会提示你改。
- 括号里只写列名，前后空格会自动忽略；不要以 `#`、`/`、`^`、`@` 开头（这些是高级写法，本工具不用）。
- 字体、字号、颜色、表格、图片、页眉页脚都照模板保留；页眉页脚里的占位符也会被替换。
- 同一个占位符可以出现多次。

**第二步：准备表格（.xlsx 或 .csv）**

每一行生成一份 Word。表头在第一行；表格上方有标题行时，把「表头在第几行」改成实际行号。日期写成 `2026-11-02`，数字按单元格里的原值填入（不带千分位，想要特定写法请在 Excel 里把这一列设成文本并写好）。

**第三步：一起拖进窗口**

1. 把**一个**模板和**一个或多个**表格一起拖进窗口（顺序无所谓）。列表里会先检查：模板显示找到了哪些占位符，表格显示有几行、有哪些列。
2. 「文件名怎么起」填例如 `{姓名}-录用通知`；不填就叫「第1份」「第2份」…；同名的自动加 (2)、(3)。
3. 点「开始处理」。检查完后自动生成，每个表格的结果放在「保存到」下以表格名命名的文件夹里。
4. 表格里缺少模板要的列时照样生成（那个位置留空），完成提示里会写明缺哪几列。

**其他说明**
- 旧版 .doc / .xls 不支持，请先另存为 .docx / .xlsx。
- 一个表格最多 5000 行；多个工作表时只用第一个有数据的工作表。
- 不支持把所有结果合成一个文档。
- 全部在本机完成，不联网、不上传。

## 验收用例

示例文件：`samples/录用通知模板.docx`（含 {姓名}{部门}{岗位}{月薪}{入职日期} 5 个占位符）、`samples/录用名单.xlsx`（5 行）。

| 操作 | 应得到 |
|---|---|
| 把两个示例文件一起拖进窗口，「文件名怎么起」填 `{姓名}-录用通知`，开始处理 | 列表里模板显示「模板：找到 5 个占位符 {姓名}{部门}{岗位}{月薪}{入职日期}」，表格显示「表格：5 行…」；完成提示「用模板「录用通知模板.docx」生成了 5 份 Word」；「保存到」下的 `录用名单` 文件夹里有 `张晓明-录用通知.docx` 等 5 个文件 |
| 打开 `李佳怡-录用通知.docx` | 写着「尊敬的 李佳怡：」「您已被录用为技术部前端工程师，月薪 15000 元（税前）」「请于 2026-11-02 上午 9:00 …」，没有残留的花括号 |
| 「文件名怎么起」清空后再处理 | 文件名为 `第1份.docx` … `第5份.docx` |
| 只拖入 `录用名单.xlsx`，开始处理 | 底部提示「收尾失败：没有可用的 Word 模板：请把写好占位符的模板（.docx）和表格一起拖进来」 |
| 在 Word 里把模板中的 `{姓名}` 改成 `｛姓名｝`（全角）后再拖入 | 模板那一行显示失败：「模板里的 ｛姓名｝ 用了全角括号，请改成英文半角的 { }…」 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
